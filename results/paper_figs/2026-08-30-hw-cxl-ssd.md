# Hardware CXL-SSD eval — 2026-08-30

## Identity (this boot)

- kernel: `6.18.0-rc5`
- FPGA: Altera `0000:15:00.0` (`ntcx` / `mem2nvme`), BAR0 **32 GiB** @ `0x22f000000000`
- NVMe transport: `nvmex` on `0000:d9:00.0` → `/dev/nvme4n1` (Dell CD8P 1.92 TB)
- Userspace device: `/dev/vmem0` **`vmem_sw`** (software-striped window + 4 GiB host cache)
- DAX / CXL memdev: **absent** (DramWindow = NUMA node1 1 GiB)
- HPS: **not live** (status register `-EOPNOTSUPP`). CPU stores to the 32 GiB BAR read back `0xff`, so BAR cannot be used as the miss window without HPS.
- `vmem.ko` now has `PREFETCH_BATCH` + bdev-fill fallback; **do not use it for numbers until BAR writes are visible**.

Do **not** write “product CXL.mem SSD” or “160 GB/s”. This is FPGA `nvmex` + software vmem.
